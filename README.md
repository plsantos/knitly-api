### 🧶 Knitly

##### Organize. Crie. Tricote.

Knitly is a full-stack application designed to help knitters organize their patterns, yarn stash, needles and knitting projects.

The application also provides yarn substitution suggestions based on yarn characteristics such as TEX, composition, weight and yardage.

#### Technologies

Backend

- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- PostgreSQL
- JUnit 5
- Mockito
- Testcontainers

Frontend

- React
